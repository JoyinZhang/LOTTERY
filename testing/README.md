## 🚀 快速开始

### 1. 运行端到端测试

```bash
# 启动测试环境
cd /data/workspace/LOTTERY
docker-compose up -d

# 执行E2E测试脚本
cd testing
bash e2e_test.sh

# 查看测试结果
cat test_results.log
```

### 2. 运行性能测试

```bash
# 使用JMeter
jmeter -n -t performance_test.jmx -l results.jtl

# 使用wrk
wrk -t12 -c1000 -d60s http://localhost:8080/api/activity/detail?activityCode=TEST

# 使用ab
ab -n 10000 -c 100 http://localhost:8080/api/activity/detail?activityCode=TEST
```

### 3. 验证部署

```bash
# 健康检查
curl http://localhost:8080/actuator/health

# API测试
curl -X POST http://localhost:8080/api/activity/create \
  -H "Content-Type: application/json" \
  -d @test_data/activity.json

# 查看服务状态
docker-compose ps
```
