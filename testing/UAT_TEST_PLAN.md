# 用户验收测试(UAT)计划

## 测试概述

### 测试目标
从最终用户角度验证系统功能是否满足业务需求,确保系统可以交付使用。

### 测试范围
- 用户使用完整流程
- 业务场景验证
- 用户体验测试
- 异常处理验证

### 测试角色

| 角色 | 职责 | 测试人员 |
|-----|------|---------|
| 活动主办方 | 创建和管理抽奖活动 | UAT测试人员A |
| 参与用户 | 参与抽奖活动 | UAT测试人员B-E |
| 系统管理员 | 监控系统运行 | UAT测试人员F |

## 业务场景测试

### 场景1: 商家促销抽奖

#### 业务背景
某电商平台在微信群开展周年庆抽奖活动,设置50份奖品,定时晚上8点开奖。

#### 测试步骤

**1. 主办方创建活动**
- [ ] 打开小程序首页
- [ ] 点击"创建抽奖"按钮
- [ ] 填写活动信息:
  - 标题: "周年庆大抽奖"
  - 说明: "感谢大家一年来的支持,50份奖品等你拿!"
  - 开奖方式: 定时开奖
  - 开奖时间: 今晚20:00
  - 奖品数量: 50份
- [ ] 点击"创建活动"
- [ ] 验证: 活动创建成功,显示活动码

**2. 分享活动到微信群**
- [ ] 点击"分享给好友"按钮
- [ ] 选择微信群
- [ ] 验证: 群里显示活动卡片
- [ ] 点击卡片可以打开活动详情

**3. 用户参与抽奖**
- [ ] 模拟100个用户点击活动链接
- [ ] 每个用户点击"立即参与"
- [ ] 授权微信信息
- [ ] 验证: 显示"参与成功,等待开奖"
- [ ] 验证: 参与人数实时更新

**4. 定时开奖**
- [ ] 等待到晚上20:00
- [ ] 验证: 系统自动开奖
- [ ] 验证: 中奖名单自动生成
- [ ] 验证: 正好50人中奖

**5. 查看中奖名单**
- [ ] 点击"查看中奖名单"
- [ ] 验证: 显示50个中奖用户
- [ ] 验证: 显示中奖时间
- [ ] 验证: 中奖者有特殊标识

#### 验收标准
- ✅ 活动创建流程顺畅,无卡顿
- ✅ 分享功能正常,卡片样式美观
- ✅ 用户参与无障碍,提示信息清晰
- ✅ 定时开奖准时触发,误差<1分钟
- ✅ 中奖人数准确,无重复
- ✅ 页面交互友好,操作简单

### 场景2: 社群运营抽奖

#### 业务背景
微信群主为活跃群氛围,设置10个红包,满100人参与立即开奖。

#### 测试步骤

**1. 创建人数开奖活动**
- [ ] 选择"人数开奖"模式
- [ ] 填写活动标题: "满100人开奖"
- [ ] 设置目标人数: 100人
- [ ] 设置奖品数: 10份
- [ ] 创建活动

**2. 分享并等待参与**
- [ ] 分享到微信群
- [ ] 实时查看参与人数进度
- [ ] 验证: 显示"已参与XX人/100人"

**3. 达到人数自动开奖**
- [ ] 第100个用户参与
- [ ] 验证: 立即触发开奖
- [ ] 验证: 所有用户收到开奖通知
- [ ] 验证: 活动状态变为"已开奖"

**4. 验证防刷机制**
- [ ] 同一用户尝试再次参与
- [ ] 验证: 提示"您已参与过该活动"
- [ ] 验证: 数据库无重复记录

#### 验收标准
- ✅ 人数统计准确实时
- ✅ 达到目标人数立即开奖
- ✅ 防重复参与有效
- ✅ 通知及时推送

---

### 场景3: 即时抽奖活动

#### 业务背景
线下活动现场扫码抽奖,20份奖品,参与即开奖。

#### 测试步骤

**1. 创建即抽即中活动**
- [ ] 选择"即抽即中"模式
- [ ] 填写活动信息
- [ ] 设置奖品数: 20份

**2. 用户参与并立即获得结果**
- [ ] 扫码参与
- [ ] 点击"立即参与"
- [ ] 验证: 立即显示中奖结果
- [ ] 中奖: 显示"恭喜中奖!"动画
- [ ] 未中奖: 显示"很遗憾,未中奖"

**3. 验证奖品库存控制**
- [ ] 模拟50个用户参与
- [ ] 验证: 中奖人数≤20人
- [ ] 验证: 第21个中奖后,剩余用户全部未中奖
- [ ] 验证: 活动状态变为"已开奖"

#### 验收标准
- ✅ 参与后立即反馈结果
- ✅ 中奖动画效果流畅
- ✅ 库存控制准确
- ✅ 不会超发奖品
