# 一、产品概述

### 1.1 项目背景
微信群抽奖是社群运营和营销活动中的常见场景，商家、社群主办方需要一个简单易用的工具来组织抽奖活动，提升群内活跃度和用户参与度。本项目复刻"微信抽奖助手"小程序的核心功能，为用户提供完整的抽奖解决方案。

### 1.2 产品定位
面向微信群场景的轻量级抽奖工具，核心功能包含活动创建、抽奖执行、中奖管理三大模块。

### 1.3 目标用户
- **主办方**：商家、社群运营者、活动组织者
- **参与者**：微信群成员、普通用户

### 1.4 MVP版本范围
MVP版本聚焦基础闭环流程，支持三种开奖模式（定时/人数/即抽即中），满足商家促销、社群运营等场景需求。

**包含功能：**
- 单奖项抽奖活动创建
- 三种开奖模式（定时开奖、人数开奖、即抽即中）
- 用户参与抽奖（微信授权）
- 自动开奖执行
- 中奖名单查看
- 基础防刷机制（OpenID去重）

**暂不包含（后续迭代）：**
- 多奖项设置
- 奖品图片上传
- 收货地址收集
- 中奖名单导出
- 数据统计看板
- 虚拟奖品自动发放

## 二、用户使用旅程
1. **创建阶段**  
   - 主办方填写奖品信息、设置开奖规则
   - 生成活动链接分享至微信群
2. **参与阶段**  
   - 用户点击链接进入活动页
   - 参与抽奖并授权微信信息
3. **开奖阶段**  
   - 系统根据规则自动开奖
   - 中奖用户填写收货信息
4. **管理阶段**  
   - 主办方查看中奖名单
   - 完成奖品发放（实物邮寄/虚拟券码）

## 五、业务规则

### 5.1 活动创建规则

1. **字段验证规则**
   - 活动标题：必填，1-24个字符
   - 奖品份数：必填，1-999的整数
   - 开奖时间：必须晚于当前时间至少5分钟
   - 目标人数：必须大于等于奖品份数

2. **创建限制**
   - 单用户每分钟最多创建3个活动
   - 单用户同时最多有50个进行中的活动

3. **活动编码生成规则**
   - 使用UUID生成唯一编码
   - 编码长度：32位
   - 仅包含字母和数字

### 5.2 参与抽奖规则

1. **参与资格**
   - 必须完成微信授权
   - 每个活动每个用户只能参与1次
   - 活动状态必须为"进行中"

2. **防刷规则**
   - 同一OpenID只能参与一次，数据库唯一索引保证
   - Redis缓存用户参与记录，快速拦截重复请求
   - 接口限流：单用户每秒1次

3. **参与成功后行为**
   - 定时开奖：返回参与成功，等待开奖
   - 人数开奖：返回参与成功，判断是否达到目标人数
   - 即抽即中：立即返回是否中奖

### 5.3 开奖执行规则

1. **定时开奖**
   - 扫描间隔：每分钟扫描一次
   - 扫描范围：开奖时间在当前分钟内且未开奖的活动
   - 并发控制：使用分布式锁，锁超时时间30秒
   - 开奖条件：至少有奖品份数同等数量的参与用户

2. **人数开奖**
   - 触发时机：用户参与成功后检查人数
   - 人数统计：Redis INCR 原子递增
   - 并发控制：分布式锁防止重复开奖
   - 开奖条件：参与人数 >= 目标人数

3. **即抽即中**
   - 抽奖时机：用户参与时立即执行
   - 中奖概率：剩余奖品数 / (奖品总数 / 预期中奖率)
   - 预期中奖率：30%（可配置）
   - 库存控制：Redis DECR 原子递减奖品库存

4. **抽奖算法**
   - 算法选型：Fisher-Yates 洗牌算法
   - 适用场景：定时开奖、人数开奖
   - 算法特点：真随机分布，每个用户中奖概率相等
   - 中奖人数：等于奖品份数

5. **开奖失败处理**
   - 参与人数不足：定时开奖时如果参与人数 < 奖品份数，全部参与用户中奖
   - 锁获取失败：跳过本次开奖，等待下次扫描
   - 系统异常：记录错误日志，发送告警，人工处理

### 5.4 中奖管理规则

1. **中奖记录生成**
   - 开奖成功后立即生成中奖记录
   - 中奖记录包含：活动ID、用户OpenID、昵称、头像、中奖时间
   - 同步更新参与记录的 is_winner 字段

2. **中奖名单查询**
   - 支持按活动ID查询所有中奖用户
   - 按中奖时间倒序排列
   - Redis缓存中奖名单，缓存1小时

3. **中奖通知**
   - MVP版本暂不实现推送通知
   - 用户需主动查询活动详情页查看是否中奖

### 5.5 活动状态管理

1. **状态流转**
   - 进行中（1）→ 已开奖（2）：开奖执行成功后自动转换
   - 进行中（1）→ 已取消（3）：用户主动取消（MVP暂不支持）

2. **状态限制**
   - 进行中：用户可以参与
   - 已开奖：不可再参与，可查看中奖名单
   - 已取消：不可参与，不可查看

| 参数校验失败 | 1001 | 根据具体字段返回对应错误信息 |

### 6.3 用户操作异常

| 异常场景 | 处理方式 |
|----------|----------|
| 用户拒绝授权 | 显示"需要授权后才能参与抽奖"，引导重新授权 |

| Token过期 | 自动调起重新授权流程 |
| 页面加载失败 | 显示空状态页，提供刷新按钮 |
